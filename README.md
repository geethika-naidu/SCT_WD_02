# 🧮 Calculator Web Application

## 📌 About the Project
This project is a fully functional Calculator Web Application developed as part of my **Web Development Internship at SkillCraft Technology**.

It performs basic arithmetic operations through a simple, user-friendly interface. The project helped me practice DOM manipulation, event handling, keyboard input, and error handling using JavaScript.

## 🎯 Objectives
- Build an interactive calculator using HTML, CSS, and JavaScript.
- Understand DOM manipulation and event listeners.
- Implement basic arithmetic operations.
- Handle user input and calculation errors.

## ✨ Features
- Addition, subtraction, multiplication, and division.
- Modulus (remainder) operation.
- Clear (AC) and delete (DEL) buttons.
- Decimal number support.
- Keyboard input support.
- Error handling for invalid calculations and division by zero.
- Responsive and user-friendly design.

## 🛠️ Technologies Used
- **HTML5** – Structure of the application.
- **CSS3** – Styling and layout.
- **JavaScript** – Calculations, DOM manipulation, and event handling.

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the calculator buttons or keyboard to perform calculations.
